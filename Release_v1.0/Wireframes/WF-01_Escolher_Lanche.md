## Wireframe de baixa fidelidade

```text
+------------------------------------------------+
|              TOTEM - LANCHONETE                |
+------------------------------------------------+
| Escolha seu lanche                              |
|                                                |
|  +----------------+  +----------------+        |
|  | [ ] LANCHE 1   |  | [ ] LANCHE 2   |        |
|  | Descrição      |  | Descrição      |        |
|  | R$ 00,00        |  | R$ 00,00        |        |
|  +----------------+  +----------------+        |
|                                                |
|  +----------------+                            |
|  | [ ] LANCHE 3   |                            |
|  | Descrição      |                            |
|  | R$ 00,00        |                            |
|  +----------------+                            |
|                                                |
|  Mensagem: selecione um lanche                 |
|                                                |
|                         [ AVANCAR ]            |
+------------------------------------------------+
```

## Legenda

- `[ ] LANCHE 1/2/3`: opções selecionáveis de lanche.
- `Descrição`: informações resumidas do item.
- `R$ 00,00`: preço ilustrativo.
- `Mensagem`: área para orientação ou erro de validação.
- `[ AVANCAR ]`: segue para a tela de pagamento após uma seleção válida.
