## Wireframe de baixa fidelidade

```text
+------------------------------------------------+
|              PEDIDO CONFIRMADO                 |
+------------------------------------------------+
| Pagamento aprovado                              |
|                                                |
| Seu pedido está pronto para preparação.        |
|                                                |
|              SUA SENHA                         |
|                                                |
|                 [ 042 ]                         |
|                                                |
| Aguarde a chamada da senha no painel.           |
|                                                |
|              [ NOVO PEDIDO ]                    |
+------------------------------------------------+
```

## Legenda

- `Pagamento aprovado`: confirmação necessária para finalizar.
- `SUA SENHA`: identificação da senha gerada.
- `[ 042 ]`: senha única exibida em destaque; valor ilustrativo.
- `Aguarde...`: orientação ao cliente após a compra.
- `[ NOVO PEDIDO ]`: reinicia o atendimento para um novo pedido.
